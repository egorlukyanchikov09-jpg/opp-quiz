# ОПП — Игровой тест (Duolingo-style)

Тест по материалам «Методика проведения сокращённых модулей по смежным компетенциям (СК) «Опытное производство поддонов»».

## Онлайн-версия

**https://egorlukyanchikov09-jpg.github.io/opp-quiz/**

## Возможности

- 20 вопросов по всем 4 модулям (роботизация, экономика, цифровые системы)
- Случайный порядок вопросов и вариантов ответов
- 3 жизни, таймер на каждый вопрос, XP
- Прогресс-бар, анимации, confetti
- **Антисписывание**: переключение вкладки / закрытие окна = статус «СПИСЫВАНИЕ», результат 0

## Результаты

После прохождения нажмите **«Скачать результат (Excel)»**.  
Файл содержит листы «Итог», «Ответы» и «История».  
Загрузите Excel в папку **Синолоджи Драйв → результаты/ОПП_тесты**.
