# ОПП · Алабуга — Игровой тест по модулям

**Онлайн:** https://egorlukyanchikov09-jpg.github.io/opp-quiz/

## Возможности
- Дизайн в сине-белых цветах Алабуги + анимации
- Разделение по модулям: **1** (робототехника), **3** (экономика), **4** (цифровые системы)
- Выбор одного или нескольких модулей
- 3 жизни, таймер, XP, антисписывание
- **Админ-панель** — только для **Лукьянчиков Егор Игоревич**
  - Введите это ФИО на старте → откроется статистика
  - Просмотр всех результатов, выгрузка Excel
- Студенты скачивают только свой результат
- Google Drive: [ОПП_результаты_тестов](https://drive.google.com/drive/folders/1YtCsu7_C-FwszX-Sq6G4R1f0OJ6O1d7l)

## Админ
На экране старта введите ФИО: `Лукьянчиков Егор Игоревич`  
(регистр не важен) — откроется панель статистики.
