# Тестирование опытного производства поддонов · Алабуга

**Онлайн:** https://egorlukyanchikov09-jpg.github.io/opp-quiz/

## Возможности
- Загрузочный экран с анимацией робота и поддонов
- Сине-белый дизайн Алабуги
- **30 вопросов** в каждом модуле (1 / 3 / 4) — выбор только одного
- Поле «Направление и номер группы» (пример: ПРОМРОБО 25-3)
- Бесконечные жизни (ошибки не останавливают тест)
- **Сирена на 100%** при списывании
- Админ: **Лукьянчиков Егор Игоревич**
- Google Drive: [ОПП_результаты_тестов](https://drive.google.com/drive/folders/1YtCsu7_C-FwszX-Sq6G4R1f0OJ6O1d7l)
